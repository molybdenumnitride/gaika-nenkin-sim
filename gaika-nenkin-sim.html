3. 市場規模 回帰

生命保険協会「生命保険の動向」の個人年金保険 新契約ANP（図表13、億円）2016〜2024年度を、米10年債利回り年度平均・USD/JPY前年度比・2016年度ダミー（標準利率改定前の駆け込み）・規制ダミー（2024年度〜）に対数線形回帰する（最小二乗、9観測×5係数）。

ln(ANPind) = a + b·rUS + c·ΔlnFX + d16·D2016 + dreg·Dreg
M = exp(a + b·rUS + c·gFX/100 + dreg·Dreg) · sFC
Mccy = M · wccy,   wAUD = 1 / (1 + exp(−(ln(0.25/0.75) + 0.6·(rAU − rUS)))),  wUSD = 1 − wAUD

推定係数と当てはまりは実績表の下に表示（更新データを読み込むと再推定）。既定データでは米10年の係数は正、同年度の円安（ΔlnFX）の係数は負（円安局面では外貨の高値掴みを避けて新規が鈍る一方、到達解約が増える＝§6の循環で拾う）、規制ダミーは負（約×0.86）。通貨配分 w は豪米金利差で動く（係数0.6は仮定）。

外貨建て比率 sFC 校正：金融庁「リスク性金融商品の個人向け販売等の状況に関する定量データ集」（2024年度9月期）では、2024年度上期の一時払保険販売額に占める外貨建ての割合は主要行等60.5%・地域銀行45.8%・大手証券91.6%（販売額加重で約58%）。ニッキン調査（地銀・第二地銀・大手信金の一時払終身）では外貨建て比率が2022年度下期83%から2024年度上期69%へ低下し、「金利ある世界」で円建てへ回帰している。この2点を日米10年金利差 Δ=rUS−rJP で結ぶロジットを既定とする。

sFC = 1 / (1 + exp(−(−4.8 + 1.75·Δ)))      校正点: Δ=3.65pt→83%, Δ=3.3pt→69%
固定モード: sFC = スライダー値（既定58%＝金融庁2024上期の販売額加重）

連動モードは2点校正のため外挿が大きい（現状のΔ≈1.9ptでは外貨建て比率が約20%まで落ちる）。金利差が縮む局面の方向感は実績と整合するが、水準は固定モードと併せて見ること。

4. 商品魅力度と多項ロジット

各商品 j（自社と競合テーブルの各行、同一通貨のもの）の効用 Uj を線形で置く。基準の予定利率 c̄ は「競合テーブルの（公表利率 − 公表時点の国債利回り）の平均」を現在の国債利回りに足した値＝市場平均商品。その他の基準は T=10、sc=5、MVAあり、f=25銭、目標到達型110%、一時払。

c̄ = rref + meanj∈同通貨(ratej − refj)
U = 2.0·(c − c̄)
  − 0.04·(T − 10) − 0.08·(sc − 5) − 0.10·[MVAあり]
  − 0.9·(φ − φ̄)                 φ = f/100/FX·100（為替手数料の片道%）, φ̄ は50銭（市場標準）
  + G                            G = {なし:−0.30, 目標到達型:0, 円元本確保:+0.25}
  − 0.02·(目標値 − 110)          （目標到達型のみ。高い目標は到達しにくく敬遠される）
  − 0.35·[平準払]

shareown = eUown / ( eUown + Σj vj·eUj + K )     vj=競合の販売力, K=その他質量

校正 校正：2017年4月の標準利率引下げ（予定利率が概ね0.5pt低下）で個人年金の新契約件数は208万件→88万件（−58%）。本モデルで自社のみ予定利率を−0.5ptすると U=−1.0、既定の競合構成でシェアは約−60%となり整合する。円金利の影響は旧版の効用ペナルティから §3 の外貨建て比率へ移した（二重計上を避ける）。解約控除・為替手数料・保証・払込形態のウェイトは仮定。

ウェイトの推定（§4の係数の出所）：商品別販売実績が非公開のため、販売担当者向けの選択型コンジョイント調査（別ページ「外貨建て年金 商品選好調査」、12問×3商品＋「提案しない」）で推定する。設計は回答者ごとに乱数シードから生成（水準: 予定利率差 −0.5〜+0.5pt、解約控除 0/4/7%、為替手数料 0/25/50銭、保証 なし/目標到達/元本確保、据置 5/10/20年、MVA あり/なし）。回答コード CJ1-シード-選択列-属性 からシミュレーター側で設計を復元し、条件付きロジット（ニュートン法、8係数）で最尤推定、標準誤差はヘッセ行列の逆行列から。推定係数は予定利率係数が2.0になるようスケールして（2017年の自然実験との整合）効用式に適用できる。推奨サンプル：30人以上（12問×30人＝360選択で主要係数のt値が2を超える見込み）。

会社横断回帰の試み（採用せず）：調査の代替として、2024年度の各社新契約ANP（第一フロンティア2,294・ニッセイ・ウェルス2,043・メットライフ1,374・T&D 896・三井住友海上プライマリー約900（収入保険料からの推定）・ジブラルタ572・PGF525・マニュライフ397・オリックス321億円）を各社の米ドル建て主力商品の仕様（利率差・解約控除・為替手数料・手数料）に対数線形回帰した。結果は R²=0.17、全係数の標準誤差が係数を上回り（利率差 0.49±0.96、解約控除 −0.02±0.19、為替手数料25銭あたり +0.16±0.53）、有意な関係は検出できない。会社規模は親会社の販売網（第一生命・日本生命・SMBC日興等）でほぼ決まり、商品仕様の差を9社の横断では識別できないため、ウェイトの出所としては採用しない。

競合テーブルの既定値 実データ：2026年7月16〜31日契約分（8社53件の横並び比較）と2026年10月1〜15日契約分の公表積立利率から、外貨建て一時払の主力商品を通貨別に収録。公表時点の10年国債（7月: 米4.60・豪4.92、10月: 米4.99・豪5.28）との差をモデルが使うため、金利が動いても相対位置が保たれる。多くは終身保険だが、銀行窓販の外貨建て一時払市場は終身・年金が同じ棚で競合するため同一市場として扱う。解約控除・MVA・為替手数料・販売手数料は各販売会社の「重要情報シート」から収録（日生: 解約控除4.0%→0／10年・為替50銭・手数料2.70%+0.30%×9年、メットライフ: 解約控除なし・50銭・4.0%+0.5%×7年、T&D: 4.5%→0.4%・為替手数料なし・3.5%+0.24%×9年、第一フロンティア: 5.5%→0・50銭・3.2〜3.4%+0.25%×9年、PGF: 7.0%→0.7%・50銭/1銭・3.1%+0.18%×14年、三井住友海上プライマリー: 4.0%→0.2%・50銭・3.5%+0.35%×9年、ニッセイ・ウェルス: 控除なし・50銭・3%+0.24%×15年）。全商品にMVAあり。マニュライフ・オリックス・ジブラルタは一部未取得（表の出所列に明記）、販売力は仮定。

5. チャネル推進力

push = Σi wi · (k / k̄)εi     k̄ = 同通貨競合の手数料率（累計）平均,  ε = {0.5, 0.4, 0.8} 粗校正

校正根拠：生保各社は2025年4月から外貨建て一時払の販売手数料を「1年目3〜4.5%→約2.5%、2年目以降0.15〜0.55%→0.5〜0.7%」へ平準化（ニッキン 2024年11月）。この前後で地銀の外貨建て一時払終身の販売件数は2024年度下期に上期比−36.2%（68,832件、ニッキン調査）。初年度手数料の実質−40%に対し販売−36%なら ε≒0.9 が上限だが、金融庁指摘・業績評価見直し・預金回帰も同時に効いているため半分程度を手数料要因とみて銀行ε=0.5とした。証券は手数料依存が低く0.4、代理店は高く0.8（仮定）。k は初年度＋継続手数料の累計で扱い、競合テーブルの重要情報シート値（日生5.4%、第一フロンティア5.5%、T&D 5.7%、PGF 5.6%、三井住友海上プライマリー6.65%、メットライフ7.5%）の平均 k̄ と比較する。

9.2 相関付き正規乱数

各シナリオ・各年度に4変量の独立標準正規乱数を発生させ、推定相関行列のコレスキー因子により相関を付与する。成分の順序は米金利、豪金利、日金利、為替とする。

Zt(s)∼i.i.d.𝒩4(0,I4),εt(s)=LZt(s),LL⊤=R^ (9.1)

したがって、推定パラメータを固定した条件下で εt(s)∼𝒩4(0,R^) となる。金利と為替の変動は同年度内で相関し、標準化した乱数は異なる年度・シナリオ間で独立と仮定する。実装の正規乱数はBox–Muller法による。コレスキー計算の対角要素には数値安定化の小さな正の下限を置く。

9.3 金利過程：下限付き離散時間平均回帰モデル

ri,t(s)=max{ℓi,ri,t−1(s)+κi(θi−ri,t−1(s))Δt+σiΔtεi,t(s)} (9.2)

平均回帰係数は全通貨で κi=0.15。金利下限はUS・AUで 0.003（0.3%）、JPで −0.003（−0.3%）とする。これは下限を適用した年次の離散式であり、連続時間モデルの厳密遷移分布を使用する実装ではない。

9.4 為替過程：年次対数正規モデル

St(s)=St−1(s)exp{gFXΔt+σFXΔtεFX,t(s)} (9.3)

本実装の入力ドリフトは、算術期待騰落率ではなく対数為替のドリフトである。したがって、その条件付き期待成長倍率は次のようになる。入力した円安トレンドから半分の分散を差し引く補正は実装していない。

𝔼ℙ[StSt−1|ℱt−1]=exp{(gFX+12σFX2)Δt} (9.4)

9.5 パラメータの標本推定

月次観測数をMとし、各月の金利を小数表示に直した上で、m＝13,…,Mの12か月変化を用いる。観測窓は重複する。ここでの年次ボラティリティは12か月変化の標本標準偏差であり、月次標準偏差を単に√12倍したものではない。

Ym=(rUS,m−rUS,m−12,rAU,m−rAU,m−12,rJP,m−rJP,m−12,logSmSm−12)⊤ (9.5)
n=M−12,Y¯=1n∑m=13MYm,C^=1n−1∑m=13M(Ym−Y¯)(Ym−Y¯)⊤ (9.6)
σa=C^aa,R^ab=C^abσaσb(a,b∈{US, AU, JP, FX}) (9.7)

金利の平均回帰水準は、q＝min(60,M)として θi=1q∑m=M−q+1Mri,m とする。標本平均の12か月変化をシナリオのドリフトに直接採用することはなく、金利には平均回帰項、為替には入力ドリフトを使う。推定値は「実績データ」に表示する。月次データが36点未満の場合は再推定せず、それまでの設定を保持する。

9.6 経済シナリオから新契約ANPへの写像

固定した前提をπ₀とし、既存の5年間売上モデルを ℳ と書く。各年度の経済状態と、当年度の算術為替騰落率をモデルに渡し、その出力の第t年度成分を取り出す。

ht(s)=St(s)St−1(s)−1 (9.8)
At(s)=[ℳ(π0;rUS,t(s),rAU,t(s),rJP,t(s),St(s),ht(s))]t (9.9)

実装へ渡す金利・為替トレンドの%値は、それぞれ100rと100hに戻す。為替の発生式で使う対数ドリフトgと、売上モデルに渡す実現した算術変化hを区別する。

現行実装は、各時点の経済状態を5年間売上モデル全体に当てはめ、第t年度のANPを抜き出す近似である。売上モデル内の保有残高はその都度初期保有から再計算するため、経路に沿って前年度の保有残高を引き継ぐ厳密な資産負債プロジェクションではない。

9.7 経験分布・順序統計量による分位点

F^t(a)=1N∑s=1N1{At(s)≤a} (9.10)

各年度のANP標本を小さい順に A(1),t≤…≤A(N),t と並べる。画面の分位点は、実装に一致する次の補間なしの順序統計量で定義する。

Q^α,t=A(kα),t,kα=1+⌊α(N−1)⌋,α∈{0.10,0.50,0.90} (9.11)

N＝1,000のとき、P10・中央値・P90は、それぞれ100番目・500番目・900番目の標本値である。帯は年度ごとのP10〜P90であり、5年間の経路全体を一定確率で覆う同時区間でも、実績値に対する信頼区間でもない。決定論の線は、現在の入力条件で経済状態を固定した元の売上モデルの値を表す。

この記載は現行コードの数理的な表現であり、計算処理の変更を伴わない。死亡・生存確率、責任準備金、割引現価、リスク中立評価を追加したものではなく、パラメータ推定誤差・競合改定・ウェイト変動も経路ごとには発生させない。

11. 画面仕様

  • 左レール：外部環境／商品仕様／販売体制・保有・収益前提。入力のたびに全出力を再計算（モンテカルロは手動実行）。
  • 効用ウェイト推定：回答コードを貼って条件付きロジットで推定→適用。動作確認用に既定ウェイトから合成回答を生成するボタンあり。
  • 競合テーブル：カタログ（competitors.json、ページと一緒に公開）から通貨・種類・チャネル・解約控除・為替手数料・保証・利率の確度・販売力で絞り込んで取得。取得後は行の追加・編集・削除が可能。通貨が自社と同じ行だけがシェア計算に入る。カタログの更新は JSON を差し替えて再公開（定期更新タスク化も可）。
  • サマリータイル：3年目のANP（うち循環分、未校正ウェイトを½〜2倍に振ったときの幅も併記）・払込総額・件数・シェア・粗利益率・想定粗利益。粗利益率 8%超=緑、3〜8%=橙、3%未満=赤。
  • 年度別予測：棒（新規ANP＋循環ANPの積上げ）と折れ線（件数）、表、CSVコピー。
  • シナリオ：名前を付けて保存（ブラウザ内）、読込・削除、全件比較表、CSVコピー、JSON書出し／読込み。
  • 不確実性：P10〜P90帯、中央値、決定論的予測。
  • 実績データ：月次チャート、回帰の当てはまりチャート（実績 vs 回帰値）、年度表、CSV取込。
  • 単一HTML・外部依存は Chart.js のみ。

12. 既知の限界

  • 市場回帰は9観測に5係数で自由度が小さい。係数の符号・大きさは年度を追加して再確認すること。
  • 外貨建て比率の連動式は地銀2点の校正で外挿が大きい。固定モードと併せて見ること。銀行・証券以外（来店型代理店・直販）の比率は未反映。
  • 競合テーブルの利率・期間・解約控除・為替手数料・手数料は公表値だが、三井住友海上プライマリーとニッセイ・ウェルスの利率、マニュライフ・オリックスの手数料系は未取得（市場標準で仮置き、出所列に明記）。販売力は置き値。
  • 魅力度ウェイトは既定では予定利率のみ校正済み。コンジョイント調査で推定・適用するまで他は置き値。調査は「販売担当者の提案意向」を測るもので、最終顧客の選好とは一致しない可能性がある。チャネル感応度は粗い校正。再購入率・到達率の為替依存は置き値。
  • 循環モデルは到達確率を簡略化（為替の経路・契約時点の為替水準を無視）。
  • 収益性は粗利益の近似。準備金・税・再保険・ヘッジコストは未考慮。

13. 商品スペック提案（制約付き全候補比較）

探索開始時の入力をスナップショットとして固定し、既存の model(p) を各商品候補に適用する。外部環境、競合、チャネル、保有・循環前提、収益前提、平均契約保険料、効用ウェイトは探索しない。通貨・払込形態は既定では現在値に固定し、比較を許可した場合だけ候補に含める。

目的関数はpremTotal の5年合計（既定）、5年間の累計ANP、または件数の5年合計。いずれも循環販売を含む。平準払の premTotal は各年度の新契約年払保険料で、過年度契約の継続払込は加算しない。制約は粗利益率（保険料比・期間累計）の下限で、既定は0%。無効にもできる。

数値項目は指定した下限から刻み幅ごとの値、上限、範囲内の現在値を重複なしで比較する。目標到達型以外では目標値を現在値に保ち、同じ商品を重複探索しない。全候補を列挙し、目的関数の降順、同値なら粗利益率の降順で上位3件を表示する。候補数は100万件まで。処理を分割して中止を受け付け、入力・ウェイト・探索設定の変更で進行中の探索を中止し、過去結果の反映を無効にする。

結果は指定した離散候補の範囲内の最大値であり、連続領域の大域最適解ではない。商品化の実現可能性、保証・MVAに伴う実務コストは既存モデルの限界に従う。反映時は商品仕様だけを変更し、元の数式・係数・データは変更しない。
